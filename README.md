# Medical Insurance Linear Regression Project

## Overview
This project performs Exploratory Data Analysis (EDA) and builds a Linear Regression model to predict medical insurance charges.

## Dataset
Medical Insurance Dataset (Kaggle)

## Steps Covered
- Data Loading and Exploration
- Exploratory Data Analysis (EDA)
- Data Preprocessing (Encoding categorical variables)
- Model Building (Linear Regression)
- Model Evaluation

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Model Performance
- MAE, MSE, R² Score used for evaluation
